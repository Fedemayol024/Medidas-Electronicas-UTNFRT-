# Medidas Electrónicas I · UTN FRT

Material de estudio para el 2º parcial (osciloscopios).

## Osciloscopio Arcade

Página web con 9 minijuegos de repaso. Funciona en la compu y en el celular, sin instalar nada.

**Jugar:** https://fedemayol024.github.io/Medidas-Electronicas-UTNFRT-/

| Juego | Qué repasa |
|---|---|
| Verdadero o Falso relámpago | Todo el temario, en 60 segundos |
| ¿Qué perilla es? | Controles del panel frontal |
| Medí la señal | Vpp y frecuencia con la retícula y la sonda |
| Compensá la sonda | Ejercicios de Rp·Cp = Ro·(Co + Cc) con animación del resultado |
| Cazá el disparo | LEVEL, SLOPE y modo AUTO/NORMAL |
| Lissajous | Desfasaje y relación de frecuencias en modo XY |
| Armá el osciloscopio | Diagramas en bloques |
| Cazador de aliasing | Muestreo y Nyquist en el osciloscopio digital |
| Panel frontal | Nombre y función de cada perilla y sección (analógico y digital), con modo explorar |

Los récords se guardan solo en el navegador de cada dispositivo.

## Guía de estudio

[Guia_Estudio_Medidas.pdf](Guia_Estudio_Medidas.pdf): guía teórica explicativa en formato celular (TRC, base de tiempo, canal vertical y horizontal, disparo, panel frontal, sonda, mediciones de tensión y corriente, osciloscopio digital), con preguntas de repaso y hoja de fórmulas. También se abre desde el menú del juego.
